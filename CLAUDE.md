# CLAUDE.md — HighExceL

Репозиторий-профиль GitHub: его README показывается на странице
[github.com/HighExceL](https://github.com/HighExceL). Кода здесь нет — только
README и картинки к нему. Отвечай и пиши по-русски.

Общие правила сети — в [../CLAUDE.md](../CLAUDE.md) и
[../CONVENTIONS.md](../CONVENTIONS.md).

## Что внутри

| Файл / папка | Что это |
|---|---|
| `README.md` | всё содержимое профиля: шапка, контакты, стек, блок активности |
| `assets/*.svg` | картинки README — рисованные, а не скриншоты: шапка, «терминал» с представлением, плашки контактов, стек, фавиконка |
| `.github/workflows/snake.yml` | ежедневная сборка «змейки» по контрибуциям |

## Чего здесь не бывает

⚠️ **Это не сайт.** Ни выкатки, ни `public/`, ни `llms.txt`, ни PWA-иконок:
показывать и индексировать нечего, страницу рисует сам GitHub. В аудите
конвенций проект стоит в `index/config/index.php` → `audit.not_a_site` именно
поэтому — иначе он вечно светился бы четырьмя красными строками.

## Как это работает

- **Картинки — SVG и только SVG.** Растр в README на ретине мылится, а тёмная
  тема GitHub требует прозрачного фона: PNG пришлось бы держать в двух
  вариантах. Правки текста внутри картинок делаются в самих `.svg`.
- **Тёмная и светлая темы.** Блок активности подставляется через
  `<picture>` с `prefers-color-scheme`; остальные картинки нарисованы так,
  чтобы читаться на обоих фонах.
- **«Змейка» живёт в ветке `output`.** Workflow гоняется по расписанию раз в
  сутки и кладёт готовые SVG туда; README ссылается на них по `raw`-адресу.
  ⚠️ Ветку `output` руками не трогать: её переписывает workflow целиком.
  ⚠️ Триггер workflow — пуш в `master`; если ветка репозитория переедет на
  `main`, обновить и его.
- **Контакты дублируют hixl.ru.** Меняются вместе: почта и Telegram здесь —
  те же, что в блоке разработчика на сайтах сети.
